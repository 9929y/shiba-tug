# 小柴的散步谈判 · Shiba Tug

一个零依赖、可直接打开的无文字互动小玩具：玩家按住红色牵引绳向左拉，拉力会被保存下来；柴犬会随拉距逐步压低身体、转向镜头抗议，最后才不情愿地挪一点点。

页面视觉只保留完整横向插画 cel 与一条无字流体进度条。手指握点、红色牵引绳、金属扣、项圈、柴犬、地面和纸张在同一张画里，因此绳子不会断开或不同步。

## 打开方式

双击 `index.html` 即可。无需安装依赖或联网。

## 操作

- 将指针停在画中的红色牵引绳上：无字小手会出现并呼吸，表示可抓取的位置
- 按住牵引绳向左拉：小手、进度条、绳的张力姿态与柴犬姿态会实时跟随拉距；短拉会弹回，拉过约舞台宽度 4% 后松开才记作一次拉动
- 键盘聚焦牵引绳后按 Enter 或空格
- 完成第三次半步后，画面会自动回到开场

没有固定的“第几次才有效”。每次有效松手都会永久保存 3.5%–14% 的拉力：短拉约需 6–8 次跨过一个半步，长拉约需 3 次。按住时，拉距依次对应收绳、加深张力、蹲低、侧脸反应、3/4 转身、正面拒绝；松手后只播放尚未经过的收尾动作。底部暖橙—米白进度条会显示已累积进度加本次预览增量，跨过三分之一里程碑时柴犬才真正滑动半步，满格后自动循环。

## 主要文件

- `index.html`：无文字 cel 舞台、无形绳子命中轨迹与无字流体进度条
- `styles.css`：逐帧 cel 舞台、暖橙—米白 Morpheus 渐变轨道、响应式与减弱动态偏好
- `game.js`：按拉距的实时预览、累积拉力状态机、60 帧逐格播放器、交替反应分支、自动循环和全帧预加载
- `assets/cels/frames/`：60 张压缩 WebP 完整场景 cel；每张均包含完整手、绳、项圈和柴犬
- `assets/cels/source/`：生成源图和过渡画源图，保留以便以后替换或扩展动作
- `assets/cels/README.md`：cel 文件清单和素材来源说明

## 视觉来源

角色动作、暖橘配色和铅笔/墨线质感由 Yanice 提供的三张柴犬参考截图确定。整幕 cel 以该方向生成，选定的源图及 WebP 生产帧均保存于项目内；所有手、绳、项圈和狗的关系均已在每一帧中直接绘制。

## 已验证

- 在本机浏览器验证：10 次标准拉力 → 进度累积到满格 → 经过 3 个推进里程碑 → 自动回到初始 cel
- 验证 60 张 WebP cel、无可见文字节点、旧的独立手/绳/狗 DOM 节点为 0、正面拒绝状态可达
- 验证 Enter 和空格触发；390px 窄屏保持完整横向场景的手—绳—项圈连接
- 生产帧预加载当前段与下一段；任一帧加载失败时停留在最后一张完整整幕 cel，不回退到旧拼装视觉
