# 小柴的散步谈判 · Shiba Tug

一个保留彩铅手绘质感的小型散步游戏。轻拉、观察、放松牵引绳，让倔柴愿意跟着挪步。

## 开始

直接打开 `index.html` 即可；也可运行 `python3 -m http.server 8766`，访问本地 8766 端口。零运行依赖、无需构建、没有外部字体或在线接口。

- 鼠标或触屏：在画面上按住向左轻拉；张力提示进入舒适区后，稍稍回松，再松手。
- 点击“轻拉一下”，或 Tab 聚焦后按 Enter / 空格，也能完成散步。
- 顶部选择黄柴 / 黑柴；切换保留进度，记住本机上次选择。目标素材准备好后统一切换，加载失败可重试。
- 猛拉会收到倔柴的正面拒绝；适度牵引会前进，回松配合有默契奖励。
- 完成后保留结果，点击“再走一圈”重新开始。

## 这次改进

- 有效操作阈值从舞台宽度 4% 改为 4 CSS 像素，视觉张力从起拉就更新。
- 新操作可以打断松手收尾；旧异步播放不能覆盖新动作，取消操作不计入进度。
- 输入事件直接更新抓取提示、张力及已解码姿势；只有行走位移和持握计时依赖刷新帧。
- 新增 7 张手绘过渡素材，替换裁脚、比例跳变的旧图，补充起拉、抬脚和落地。补帧没有延长松手动画。
- 22 个共用动作坐标，黄柴和黑柴各一套，共 44 张在用图片。三个散步阶段共享完整动作资源，位移连续保存。
- 手和狗按原比例绘制；渲染时仅收短中间绳段，狗每次成功操作都可见地向左移动。手机构图裁去远端袖口、缩短空白绳跨距，保留完整柴犬。
- 替换卡通悬浮手和波纹，使用轻量抓取光圈、纸色 UI、双柴肖像、张力提示、散步路线和完成页。

## 文件

- `game.js`：输入、取消与中断、图片解码、位移渲染、切换、完成与重玩。
- `mechanics.js`：轻拉评估与绳段坐标映射，供浏览器和测试共用。
- `frames.js` / `black-frames.js`：两种柴犬的动作清单。
- `assets/cels/frames/`：原有整幕图片，保留原始三段素材。
- `assets/cels/inbetweens/`：新增黄柴中间帧。
- `assets/cels/black/`：匹配黑柴动作。
- `assets/cels/source/v2/`：本轮生成源图。发布网站只需清单引用的 WebP，无需发布 source。
- `tests/interaction.test.cjs`：状态、取消、位移、切换、失败恢复与低动态偏好测试。
- `tests/browser-check.html`：浏览器内交互、资源与 390px 布局检查。
- `tests/art-review.html`：原版与补帧样段对照。
- `docs/reviews/`：基线、设计和验证记录。

## 验证

运行 `node --test tests/interaction.test.cjs`。浏览器中打开 `tests/browser-check.html`，点击运行检查。

已检查真实鼠标拖拽、Enter / 空格、双柴切换，以及浏览器中合成触摸 PointerEvent。390px 是响应式浏览器验证，不代表已经在实体手机上完成测试。输入派发到下一次 rAF 的测量也不等于物理触屏到显示的总延迟。

插画仍是离散手绘动作，保留线条与纸纹的细小差异；本轮解决操作死区、输入锁定、严重裁切与位置跳回，没有宣称生成了逐像素一致的插值动画。

## 美术

延续原项目暖纸色、棕色轮廓、彩铅毛发与红色牵引绳。新增素材使用内置 imagegen，以对应原图为参考编辑。黑柴先确定站立配色，再逐帧匹配同姿势；没有使用全画面变色滤镜。各素材目录 README 记录参考和提示词约束。

发布压缩包不含体积较大的生成源 PNG；本地完整 Git 仓库保留这些素材和所有提交。
