# 拉绳遛柴

全屏纸感的手绘牵引小游戏。按住红色牵引绳向左拖动，松手迈步；头像切换黄柴和黑柴。

## 运行

在本目录执行 `python3 -m http.server 8767 --bind 127.0.0.1`，浏览器打开 http://127.0.0.1:8767/ 。纯静态网页，无构建步骤、后端或运行时依赖。不要直接双击 HTML：资源处理需要同源 HTTP。

## 游戏规则

- 拉动时淡色进度预览本次收益，松手后实色进度随迈步增加。
- 完整拉伸距离为舞台宽度的 24%，限制为 90–220 CSS px。
- 拉伸不足 8% 不增加进度；8%–25% 小步；25%–70% 连续增益；70%–90% 增益递减；达到 90% 拒绝。
- 适当回松额外奖励 2%，单次最多 14%。过拉后回到 25%–70% 并保持 150ms 即可恢复。
- 黑柴拒绝时轮换得意眯眼和大笑，回松后讨好；黄柴拒绝时委屈、歪头，成功后开心。成功动作轮换表情。
- 完成路程播放 5.2 秒走进家门、回头摇尾巴动画，停留后可重玩。
- 可聚焦牵引区域，按住左方向键拉动、右方向键回松，全部释放结算。减少动态效果设置下缩短迈步和结尾。
