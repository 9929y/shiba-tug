# Walking, rather than a hidden tug counter

- All three chapters now use the reviewed chapter-one coordinate system and its seven new cels, so later chapters receive the same uncropped transitions. Original chapter files are retained as art sources.
- `mechanics.js` separates gentle-pull judgment from rendering. Moderate tension earns a step, a deliberate easing before release earns a trust bonus, excessive peak force triggers refusal with no distance reward. Keyboard/click is a supported gentle action, without demanding precise timing.
- Every successful pull advances distance. The canvas renders the original full cel in three contiguous spans: rigid hand, shortened leash span, rigid dog translated left. No dog stretching, independently drawn rope, or alpha morph. Only the existing far-right paper fills revealed space. Maximum dog translation is 220 source pixels.
- Position easing lasts 620ms and runs independently from pose playback. New input can interrupt pose playback without losing committed position.
- Completion persists until the user restarts. Restart invalidates pending work and clears distance/results.
- New semantic progress, tension and status controls accompany the loop; final styling and dual-breed controls are the next passes.

Verification:
- `node --test tests/interaction.test.cjs`: five rules/state regression tests pass, including rapid interruptions, canceled input, rigid geometry and persistent finish/restart.
- Browser: 5 consecutive gentle button activations reach 59%, chapter 2, with the dog visibly farther left and leash remaining attached. No reload or forced wait was required between inputs.
