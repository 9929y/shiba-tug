# Shiba Tug full-scene cels

`frames/` contains the 36 compressed production WebP cels used by the browser: 12 each for chapters one, two and three. Every cel is 1536×512 and contains the whole shot: sleeve, complete hand, continuous red leash, metal attachment, collar, Shiba and paper ground.

`source/` contains the 18 selected 1536×1024 two-cel source sheets. They are retained because they are the direct source for the WebP production frames and make it possible to add in-betweens later without reconstructing the visual direction.

Visual direction is based on the three Shiba reference screenshots supplied by Yanice in this conversation: warm orange/cream Shiba, brown-black pencil contours, handmade colored-pencil fur, warm ivory paper, and a red leash. The generated source images are project assets; original generation cache files remain outside this project.
