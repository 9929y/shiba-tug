# Shiba Tug full-scene cels

`frames/` contains the 60 compressed production WebP cels used by the browser: 20 each for chapters one, two and three. Every cel is 1536×512 and contains the whole shot: sleeve, complete hand, continuous red leash, metal attachment, collar, Shiba and paper ground.

`source/` contains the original 18 selected two-cel source sheets plus the transition-generation sheets used for added take-up, tension, crouch, 3/4 turn and slide cels. They are retained because they are the direct source for the WebP production frames and make it possible to add later in-betweens without reconstructing the visual direction.

Visual direction is based on the three Shiba reference screenshots supplied by Yanice in this conversation: warm orange/cream Shiba, brown-black pencil contours, handmade colored-pencil fur, warm ivory paper, and a red leash. The generated source images are project assets; original generation cache files remain outside this project.
